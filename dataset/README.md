# Knowledge Nexus LATAM — Data V1.0 RC2

Dataset institucional sintético para el reto internacional.

Estructura:
- 01_institution: estructura académica, grupos, líneas y capacidades.
- 02_people_curriculum: investigadores, expertise y currículo.
- 03_knowledge_needs: necesidades, proyectos, tesis, publicaciones y documentos complementarios.

Los identificadores permiten integrar entidades entre archivos. Los participantes deben preservar trazabilidad hacia las fuentes utilizadas y justificar las conexiones propuestas.
