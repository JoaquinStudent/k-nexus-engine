# Modelo institucional para evidencias de aprendizaje y su relación con rubric analysis

**Project ID:** PRJ-018  
**Status:** FORMULATION  
**Period:** 2022–2023

## Problem
La información sobre evidencias de aprendizaje se encuentra distribuida y existen dificultades para relacionarla con rubric analysis de manera verificable.

## Summary
Proyecto orientado a estudiar evidencias de aprendizaje y su relación con rubric analysis, integrando evidencia institucional y un enfoque de clasificación de textos.

## General objective
Desarrollar y evaluar un enfoque de clasificación de textos que permita analizar evidencias de aprendizaje y generar evidencia útil para rubric analysis.

## Methodological notes
Integración de fuentes, preparación de datos, clasificación de textos, análisis comparativo y validación de resultados.

## Expected results
Se esperan relaciones priorizadas, evidencia reproducible y orientaciones para decisiones relacionadas con rubric analysis.

## Institutional context
rubric analysis
