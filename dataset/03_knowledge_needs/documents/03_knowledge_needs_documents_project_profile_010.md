# Modelo institucional para personalización y su relación con learning analytics

**Project ID:** PRJ-010  
**Status:** ACTIVE  
**Period:** 2021–2022

## Problem
La información sobre personalización se encuentra distribuida y existen dificultades para relacionarla con learning analytics de manera verificable.

## Summary
Proyecto orientado a estudiar personalización y su relación con learning analytics, integrando evidencia institucional y un enfoque de analítica educativa.

## General objective
Desarrollar y evaluar un enfoque de analítica educativa que permita analizar personalización y generar evidencia útil para learning analytics.

## Methodological notes
Integración de fuentes, preparación de datos, analítica educativa, análisis comparativo y validación de resultados.

## Expected results
Se esperan relaciones priorizadas, evidencia reproducible y orientaciones para decisiones relacionadas con learning analytics.

## Institutional context
learning analytics
