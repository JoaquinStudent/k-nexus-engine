# Integración de evidencia sobre evidencias de aprendizaje en escenarios de rubric analysis

**Project ID:** PRJ-023  
**Status:** FORMULATION  
**Period:** 2018–2019

## Problem
La información sobre evidencias de aprendizaje se encuentra distribuida y existen dificultades para relacionarla con rubric analysis de manera verificable.

## Summary
Proyecto orientado a estudiar evidencias de aprendizaje y su relación con rubric analysis, integrando evidencia institucional y un enfoque de procesamiento de lenguaje natural.

## General objective
Desarrollar y evaluar un enfoque de procesamiento de lenguaje natural que permita analizar evidencias de aprendizaje y generar evidencia útil para rubric analysis.

## Methodological notes
Integración de fuentes, preparación de datos, procesamiento de lenguaje natural, análisis comparativo y validación de resultados.

## Expected results
Se esperan relaciones priorizadas, evidencia reproducible y orientaciones para decisiones relacionadas con rubric analysis.

## Institutional context
rubric analysis
