# Integración de evidencia sobre personalización en escenarios de learning analytics

**Project ID:** PRJ-015  
**Status:** ACTIVE  
**Period:** 2026–ongoing

## Problem
La información sobre personalización se encuentra distribuida y existen dificultades para relacionarla con learning analytics de manera verificable.

## Summary
Proyecto orientado a estudiar personalización y su relación con learning analytics, integrando evidencia institucional y un enfoque de sistemas recomendadores.

## General objective
Desarrollar y evaluar un enfoque de sistemas recomendadores que permita analizar personalización y generar evidencia útil para learning analytics.

## Methodological notes
Integración de fuentes, preparación de datos, sistemas recomendadores, análisis comparativo y validación de resultados.

## Expected results
Se esperan relaciones priorizadas, evidencia reproducible y orientaciones para decisiones relacionadas con learning analytics.

## Institutional context
learning analytics
