# Análisis aplicado de permanencia estudiantil para fortalecer trayectorias educativas

**Project ID:** PRJ-001  
**Status:** ACTIVE  
**Period:** 2019–2020

## Problem
La información sobre permanencia estudiantil se encuentra distribuida y existen dificultades para relacionarla con trayectorias educativas de manera verificable.

## Summary
Proyecto orientado a estudiar permanencia estudiantil y su relación con trayectorias educativas, integrando evidencia institucional y un enfoque de clasificación supervisada.

## General objective
Desarrollar y evaluar un enfoque de clasificación supervisada que permita analizar permanencia estudiantil y generar evidencia útil para trayectorias educativas.

## Methodological notes
Integración de fuentes, preparación de datos, clasificación supervisada, análisis comparativo y validación de resultados.

## Expected results
Se esperan relaciones priorizadas, evidencia reproducible y orientaciones para decisiones relacionadas con trayectorias educativas.

## Institutional context
trayectorias educativas
