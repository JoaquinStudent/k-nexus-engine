# Modelo institucional para competencias y su relación con evaluación formativa

**Project ID:** PRJ-022  
**Status:** ACTIVE  
**Period:** 2026–ongoing

## Problem
La información sobre competencias se encuentra distribuida y existen dificultades para relacionarla con evaluación formativa de manera verificable.

## Summary
Proyecto orientado a estudiar competencias y su relación con evaluación formativa, integrando evidencia institucional y un enfoque de analítica curricular.

## General objective
Desarrollar y evaluar un enfoque de analítica curricular que permita analizar competencias y generar evidencia útil para evaluación formativa.

## Methodological notes
Integración de fuentes, preparación de datos, analítica curricular, análisis comparativo y validación de resultados.

## Expected results
Se esperan relaciones priorizadas, evidencia reproducible y orientaciones para decisiones relacionadas con evaluación formativa.

## Institutional context
evaluación formativa
