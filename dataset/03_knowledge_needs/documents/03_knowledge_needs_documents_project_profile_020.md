# Estrategia basada en procesamiento de lenguaje natural para estudiar rubric analysis

**Project ID:** PRJ-020  
**Status:** COMPLETED  
**Period:** 2024–2025

## Problem
La información sobre rubric analysis se encuentra distribuida y existen dificultades para relacionarla con competencias de manera verificable.

## Summary
Proyecto orientado a estudiar rubric analysis y su relación con competencias, integrando evidencia institucional y un enfoque de procesamiento de lenguaje natural.

## General objective
Desarrollar y evaluar un enfoque de procesamiento de lenguaje natural que permita analizar rubric analysis y generar evidencia útil para competencias.

## Methodological notes
Integración de fuentes, preparación de datos, procesamiento de lenguaje natural, análisis comparativo y validación de resultados.

## Expected results
Se esperan relaciones priorizadas, evidencia reproducible y orientaciones para decisiones relacionadas con competencias.
