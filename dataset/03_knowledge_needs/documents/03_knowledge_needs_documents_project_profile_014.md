# Modelo institucional para aprendizaje adaptativo y su relación con secuencias de aprendizaje

**Project ID:** PRJ-014  
**Status:** FORMULATION  
**Period:** 2025–2026

## Problem
La información sobre aprendizaje adaptativo se encuentra distribuida y existen dificultades para relacionarla con secuencias de aprendizaje de manera verificable.

## Summary
Proyecto orientado a estudiar aprendizaje adaptativo y su relación con secuencias de aprendizaje, integrando evidencia institucional y un enfoque de modelamiento de usuarios.

## General objective
Desarrollar y evaluar un enfoque de modelamiento de usuarios que permita analizar aprendizaje adaptativo y generar evidencia útil para secuencias de aprendizaje.

## Methodological notes
Integración de fuentes, preparación de datos, modelamiento de usuarios, análisis comparativo y validación de resultados.

## Expected results
Se esperan relaciones priorizadas, evidencia reproducible y orientaciones para decisiones relacionadas con secuencias de aprendizaje.

## Institutional context
secuencias de aprendizaje
