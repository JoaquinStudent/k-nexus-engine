# Análisis aplicado de recuperación semántica para fortalecer similitud conceptual

**Project ID:** PRJ-029  
**Status:** COMPLETED  
**Period:** 2026–ongoing

## Problem
La información sobre recuperación semántica se encuentra distribuida y existen dificultades para relacionarla con similitud conceptual de manera verificable.

## Summary
Proyecto orientado a estudiar recuperación semántica y su relación con similitud conceptual, integrando evidencia institucional y un enfoque de NLP.

## General objective
Desarrollar y evaluar un enfoque de NLP que permita analizar recuperación semántica y generar evidencia útil para similitud conceptual.

## Methodological notes
Integración de fuentes, preparación de datos, NLP, análisis comparativo y validación de resultados.

## Expected results
Se esperan relaciones priorizadas, evidencia reproducible y orientaciones para decisiones relacionadas con similitud conceptual.
