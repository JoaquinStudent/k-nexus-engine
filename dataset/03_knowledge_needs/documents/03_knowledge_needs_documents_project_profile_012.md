# Estrategia basada en sistemas recomendadores para estudiar learning analytics

**Project ID:** PRJ-012  
**Status:** COMPLETED  
**Period:** 2023–2024

## Problem
La información sobre learning analytics se encuentra distribuida y existen dificultades para relacionarla con aprendizaje adaptativo de manera verificable.

## Summary
Proyecto orientado a estudiar learning analytics y su relación con aprendizaje adaptativo, integrando evidencia institucional y un enfoque de sistemas recomendadores.

## General objective
Desarrollar y evaluar un enfoque de sistemas recomendadores que permita analizar learning analytics y generar evidencia útil para aprendizaje adaptativo.

## Methodological notes
Integración de fuentes, preparación de datos, sistemas recomendadores, análisis comparativo y validación de resultados.

## Expected results
Se esperan relaciones priorizadas, evidencia reproducible y orientaciones para decisiones relacionadas con aprendizaje adaptativo.

## Institutional context
aprendizaje adaptativo
