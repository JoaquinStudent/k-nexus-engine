# Institutional Need — Monitoreo remoto cardiovascular

**Need ID:** NEED-005  
**Priority:** HIGH  
**Status:** OPEN

## Description
La institución requiere fortalecer su capacidad para abordar monitoreo remoto cardiovascular mediante el aprovechamiento articulado de información, conocimiento previo y capacidades existentes. El problema se expresa en términos de monitoreo cardiovascular, ECG y wearables, sin prescribir una solución tecnológica específica.

## Context
Necesidad institucional identificada para mejorar decisiones y articular capacidades relacionadas con monitoreo cardiovascular.

## Expected institutional impact
Mayor capacidad institucional, trazabilidad de decisiones y generación de oportunidades interdisciplinarias.

This document intentionally does not prescribe an algorithm, model, or technology.
